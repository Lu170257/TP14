Glosario

Definición de términos

  • Algoritmo: Es una secuencia ordenada de pasos para resolver un problema.
  • Archivo: Un archivo son datos guardados con un nombre.
  • Archivo.bat: Es un archivo de procesamiento que contiene comandos para Windows.
  • Bloque: Pieza que representa una acción.
  • Bucle: Es una instrucción que se repite indefinidamente o hasta que se cumpla otro evento.
  • Branch:es una copia independiente de una línea de desarrollo dentro de un repositorio. Permite trabajar en nuevas funciones o cambios sin afectar la versión principal del proyecto.
  • Carpeta: Una carpeta es un lugar donde se guardan distintos archivos y carpetas para tenerlos de forma organizada.
  • Clon: crea una copia local de un repositorio remoto
  • CMD: El CMD es la consola de Windows que se utiliza para ejecutar comandos.
  • Comando: Los comandos son instrucciones que le da el usuario a la PC para que las ejecute.
  • Commit: es un registro o guardado de los cambios realizados en un proyecto, acompañado de un mensaje que describe qué se modificó
  • Condicional: Ejecución de pasos que se realiza mientras se cumpla una condición.
  • Copy: Comando de la consola de Windows que se utiliza para copiar archivos.
  • CSS: Lenguaje que define el diseño y la apariencia de una página web.
  • Echo: Comando de la consola de Windows que se utiliza para colocar mensajes.
  • Extensión: Una extensión es lo que se encuentra al final de un archivo para saber qué tipo de archivo es, por ejemplo: .txt, .jpg, .bat.
  • Fetch: Descarga los cambios del repositorio remoto, pero sin aplicarlos automáticamente
  • Fork: es una copia de un repositorio que permite realizar cambios sin afectar el proyecto original. Se utiliza para contribuir a proyectos de otros usuarios o para experimentar con nuevas ideas.
  • Git: Sistema de control de versiones distribuido que registra los cambios en el código a lo largo del tiempo, permitiendo revertir estados anteriores y trabajar en equipo sin sobrescribir información.
  • GitHub: Es una plataforma que te permite guardar, compartir, y trabajar en proyectos de programación o diseño web de forma colaborativa
  • Google Drive: Servicio que se utiliza para trabajar y guardar datos en la nube.
  • HTML: Lenguaje que estructura el contenido de una página web.
  • IDE: Programa que reúne herramientas para escribir, editar y ejecutar código en un solo lugar.
  • JavaScript: Lenguaje de programación que añade interactividad y dinamismo a una página web.
  • Merge (fusión): es el proceso de unir los cambios de una branch (rama) con otra.
  • Mkdir: Comando de la consola de Windows utilizado para crear directorios.
  • Pull: es el proceso de obtener los cambios más recientes de un repositorio remoto y fusionarlos con tu copia local del proyecto.
  • Push: es el proceso de enviar los cambios realizados en tu copia local de un proyecto a un repositorio remoto, actualizando así la versión del proyecto en línea.
  • PSeInt: Programa que se utiliza para aprender mediante pseudocódigos.
  • Repositorio: Es un lugar donde se guardan los archivos de un proyecto, junto con su historial de cambios y versiones.
  • Scratch: Es un lenguaje de programación por bloques utilizado para aprender cómo programar.
  • Script: Conjunto de instrucciones que se ejecutan automáticamente.
  • Trabajo colaborativo: Manera de trabajar para que varias personas participen en una misma tarea.
  • Variable: Espacio de datos que puede variar mientras se ejecuta el código.
